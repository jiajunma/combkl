primary_topic: kl.localization

Fix a current edge and the two outgoing selections determined by its target-root threshold. In a structure model supported at a center above the upper endpoint, the selected edge images are products of supported labels in the actual edge quotient. Distinct selected roots reduce to associates of one reference root.

The supported endpoint counts differ by the geometric plane weight. The correction factor reduces to the same reference root raised to that weight. Thus the lower product and the corrected upper product differ by a unit and generate equal image submodules. A model not supporting the current edge has zero edge module, so its equality is immediate.

The same correction scalar works in every model summand. The [[node:kl.local.localized_decomposition|localized boundary decomposition]] carries both images through one linear edge component, giving equality in the actual localized boundary sheaf. Pullback identities then recover the ambient endpoint kernels and restrictions. This is the local equality that the [[node:kl.local.edge_inclusion|global edge inclusion]] uses.
