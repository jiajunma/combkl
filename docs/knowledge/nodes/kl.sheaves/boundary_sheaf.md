# Minimal-boundary sheaves

Fix a nonnegatively graded coefficient ring, a labelled ordered graph, and a top vertex \(b\). Vertex and edge modules are finite nonnegatively graded modules. A minimal-boundary sheaf has the following properties:

- Every vertex module is free.
- The upper restriction at each edge presents its edge module as the quotient by the edge label.
- Sections on subsets closed upward along edges extend globally.
- Global sections generate each vertex module.
- The module at \(b\) is the rank-one free module generated in degree zero.
- At every \(x\ne b\), the kernel of the map to the upper boundary image lies in the positive-degree ideal times the vertex module.

These conditions organize the descending minimal-boundary construction. Freeness of terminal kernels and the character identities are established by subsequent theorems.

## Building the sheaf on one edge

Consider a graph with one edge \(x\to b\), labelled by a nonzero linear form \(\alpha\). Set \(B^b=A\) and \(B^e=A/(\alpha)\). The upper boundary image at \(x\) is \(A/(\alpha)\), so its minimal free cover is the quotient map from \(A\). Thus \(B^x=A\), and both restrictions are reduction modulo \(\alpha\).

A global section is a pair \((f_x,f_b)\) with
\[
f_x-f_b\in(\alpha).
\]
Each stalk is generated by global sections: any polynomial can be used at both vertices. The full upward kernel at \(x\) is \(\alpha A\), while the empty-condition kernel is \(A\).

With root labels in degree one, these two free modules have graded ranks \(q\) and \(1\), respectively. This is the simplest model of the reciprocal endpoints of the later Hilbert-state process. For several edges, the boundary image must first account for compatibility above the vertex, which is why the general construction uses [[node:kl.notes.boundary_image]].
