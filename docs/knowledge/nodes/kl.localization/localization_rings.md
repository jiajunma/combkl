# Root quotients and root-plane localization rings

Let \(A=\operatorname{Sym}_{\mathbb R}(V)\), where \(V\) is the extended realization, and regard \(a\in V\) as the degree-one polynomial \(\iota(a)\). The root line and root ideal are
\[
\mathbb Ra\subseteq V,\qquad (a)=(\iota(a))\subseteq A.
\]
The edge coefficient ring is \(A/(a)\). Reducing another root means taking its actual image in this quotient.

For a root plane \(P\subseteq V_0\), first embed it into \(V\). Let \(\mathfrak p_P\) be the ideal generated by all its linear polynomials. After choosing polynomial coordinates, the same ideal is transported through \(\operatorname{Sym}(V)\simeq\mathbb R[X_1,\ldots,X_N]\). The root-plane ring is
\[
A_{\mathfrak p_P}=(A\setminus\mathfrak p_P)^{-1}A.
\]
It inverts exactly the elements outside the prime ideal. In particular, a root label is invertible there exactly when its root does not lie in \(P\).

For a distinguished root \(a\), the localized edge ring is
\[
A_{\mathfrak p_P}/(a/1).
\]
Thus two operations occur: localizing at the plane ideal and then setting the selected edge root to zero. The ideal is defined for any linear subspace; the geometric application chooses a plane. The quotient-and-primality theorem explains why these are legitimate prime localizations.
