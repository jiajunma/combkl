# Root-plane subgroups and relative Bruhat order

Fix a two-dimensional plane \(P\) spanned by root directions. Let \(D_P\) be the subgroup generated by reflections with roots in \(P\). The root-plane subgroup has a canonical dihedral Coxeter structure, and therefore its own length function \(\ell_D\) and strong Bruhat order \(\le_D\).

For a coset \(D_Pa_0\), choose \(a_0\) of minimal ambient length. Write its elements as \(da_0\), and transfer the canonical dihedral order along \(d\mapsto da_0\). A relative interval is
\[
[x,c]_D=\{z:x\le_D z\le_D c\}.
\]
Its rank difference uses \(\ell_D\), not the ambient length function.

The directed relative reflection edges agree with the corresponding ambient reflection edges in the coset. Following a relative path therefore gives an ambient Bruhat path. The ambient order may also contain paths leaving the coset, so equality of the two partial orders is not part of the setup.

A dihedral interval of rank \(n\ge2\) has one bottom vertex, one top vertex, and two vertices in each internal rank. Consecutive ranks have all the expected covering connections. This rigid shape, together with the two-edge path criterion, permits an unlabelled ambient interval isomorphism to recover and transport the relative interval.
